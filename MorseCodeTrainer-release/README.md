# Morse Code Trainer

**Morse Code Trainer** — це Qt Widgets-застосунок для вивчення азбуки Морзе через довідник символів, тестування, перевірку відповідей і перегляд статистики прогресу.

## Можливості MVP

- головний екран із прогресом вивчення;
- вибір тесту зі списку;
- проходження тесту з покроковими завданнями;
- введення Morse code через кнопки, клавіатуру або пробіл;
- автоматичний переклад введеного коду;
- перевірка відповіді та підрахунок точності;
- довідник символів із пошуком і фільтром;
- статистика: результати тестів, середня точність, слабкі символи;
- збереження прогресу та налаштувань;
- скидання прогресу з підтвердженням.

## Технології

- C++17
- Qt 6 Widgets
- Qt Sql
- CMake
- QSettings
- локальні текстові файли з тестами та символами

## Структура застосунку

- `MainWindow` — головне вікно зі сторінками застосунку;
- `DashboardWidget` — стартовий екран із прогресом;
- `LessonSelectionWidget` — вибір тесту;
- `TrainingWidget` — проходження тесту;
- `ReferenceWidget` — довідник символів;
- `StatisticsWidget` — екран статистики;
- `SettingsDialog` — налаштування;
- `AboutDialog` — вікно про програму;
- `SessionSummaryDialog` — підсумок сесії;
- `ConfirmResetDialog` — підтвердження скидання прогресу;
- `MorseEncoder` — кодування та декодування Morse code;
- `TestManager` — завантаження тестів;
- `SettingsManager` — читання та збереження налаштувань;
- `DatabaseManager` — збереження статистики.

## Дані програми

Застосунок використовує такі зовнішні файли:

- `data/symbols.txt` — список символів азбуки Морзе;
- `data/tests/` — папка з тестами у текстових файлах.

Під час роботи зберігаються:

- виконані тести;
- точність проходження;
- прогрес окремих символів;
- мовні та інші налаштування.

## Як зібрати проєкт

### Через Qt Creator

1. Відкрити проєкт через `CMakeLists.txt`.
2. Обрати комплект Qt 6.
3. Зібрати проєкт у конфігурації **Release**.

### Через CMake

```bash
cmake -S . -B build
cmake --build build --config Release
```

## Як запустити

Після збірки запустити виконуваний файл застосунку.

Для коректної роботи поруч із `.exe` мають бути:

- папка `data/`;
- файл `data/symbols.txt`;
- папка `data/tests/`.

Якщо створюється релізна папка для Windows, після копіювання `.exe` потрібно виконати `windeployqt`, щоб додати потрібні бібліотеки Qt і папку `platforms/`.

Приклад:

```bash
windeployqt MorseCodeTrainer.exe
```

## Інструкція користувача

1. Відкрити застосунок.
2. Натиснути **Start Test**.
3. Обрати тест у списку.
4. Натиснути **Start**.
5. Вводити код Морзе за допомогою кнопок, клавіатури або пробілу.
6. Натискати **Next** для переходу до наступного завдання.
7. Після завершення переглянути підсумок тесту.
8. За потреби відкрити **Morse Alphabet** або **Statistics**.

## Демо-сценарій

1. Запустити застосунок.
2. Показати головний екран і прогрес.
3. Відкрити список тестів.
4. Обрати тест.
5. Пройти кілька завдань у режимі Training.
6. Показати екран із результатом.
7. Відкрити довідник символів.
8. Відкрити статистику та показати слабкі символи.
9. Відкрити налаштування та змінити мову або спосіб введення.
10. Підтвердити, що прогрес і налаштування зберігаються.

## Налаштування

У застосунку можна змінити:

- мову інтерфейсу та навчання;
- введення з клавіатури;
- введення через пробіл.

Після натискання **Save** налаштування застосовуються і зберігаються.

## Відомі обмеження

- дані зберігаються локально;
- немає авторизації користувачів;
- застосунок орієнтований на desktop-формат;
- набір функцій відповідає MVP;
- релізна папка має містити зовнішні файли даних поруч із виконуваним файлом.
